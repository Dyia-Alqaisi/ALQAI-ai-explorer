# ALQAI Workshop

Interactive one-hour AI workshop presentation, with separate Arabic and English interfaces.

## Open

https://dyia-alqaisi.github.io/ALQAI-ai-explorer/workshop/

Use the language selector at the top. Supports configurable image, audio and pose activities. Training happens in Teachable Machine; the presentation simulations do not train models.

## Controls

- Arrow keys / Previous and Next: navigate the 12 scenes.
- N: presenter notes (visible on the projector when opened).
- F: fullscreen.
- My activities: configure project type and 2–6 target classes, or switch activities. Audio includes an additional background noise class.

Activity settings, language and test scores are stored in the current browser only. Model data and trained models are managed separately in Teachable Machine.

## Local preview

Serve this folder with any static HTTP server and open index.html. No build or dependency installation is required. Keep both JavaScript files beside index.html.

The parent folder contains the separate AI Explorer booth website.
