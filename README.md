# ALQAI AI Explorer

A bilingual Arabic/English interactive AI discovery website for students and the ALQAI booth.

## Included

- Interactive animated AI network with reduced-motion controls.
- AI fields and a simplified learning simulation.
- Six-round real-photograph vs AI-generated image challenge with source reveals.
- ALQAI CAM component explorer (educational diagram, not a live hardware connection).
- Career exploration, interest questions and beginner learning resources.
- Mobile layouts, keyboard-operable tabs and a visitor reset.

## Run

Open `index.html` in a modern browser, or serve this directory with a local static web server. No build, package installation, API key or backend is required.

## Publish with GitHub Pages

In this repository: Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main > Folder: / (root) > Save.

The QR code currently opens the original live site: https://alqai-ai-explorer.minions-bodies.chatgpt.site

## Content and assets

Educational references and image credits are available inside the website under Sources & image credits. Photographs are credited to Martin Pedersen, fady haff and Annie Spratt on Unsplash. Three quiz images were generated using OpenAI. Image labels document provenance rather than a detector result.

The learning sequence is a preset educational simulation, not in-browser model training. Interest results suggest areas to explore, not a degree or aptitude decision. Only the language preference is stored locally.
